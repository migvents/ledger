Current prices

Type each fund's price from Revolut once and save. From then on the app moves each price in step with its US-listed twin and the EUR/USD rate, refreshing every minute while open. Re-type a Revolut price whenever you want to re-anchor (a good habit at the January check).

Rules

Sync between devices

Set this up once per device. After that every change uploads by itself, and the app checks for changes from your other device every minute while it is open. Safety rules: a device with no transactions never overwrites the cloud; a failed pull never triggers an upload; a cloud copy with fewer transactions than this device is not applied without asking. Every cloud version is kept and can be restored from Cloud versions.

Your data

Data is stored in this browser and, if sync is set up, in your encrypted gist. Export a backup now and then.
